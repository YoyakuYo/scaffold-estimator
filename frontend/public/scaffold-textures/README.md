# Scaffold reference textures (3D realistic view)

Place your reference images here so the 3D scaffold view can use them as materials.
Use these exact base names (with `.png`, `.jpg`, or `.jpeg`):

- **post** — 支柱 (scaffolding post ø48.6, MA series)
- **jack-base** — ジャッキベース (adjustable jack base)
- **plank** — 踏板 Anchi (perforated metal plank)
- **nuno** — 布材 / 手摺 (nuno bars / ledgers with hook ends)
- **brace-handrail** — ブレス・手摺 (X-brace with handrail)
- **habaki** — 巾木 (toe board; optional)

The viewer will load them and apply them to the 3D components. If a file is missing, that component falls back to the standard solid material.
