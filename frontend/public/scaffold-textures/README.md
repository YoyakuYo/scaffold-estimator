# Scaffold reference textures (3D realistic view)

Place your reference images here so the 3D scaffold view can use them as materials.
Use these exact filenames (case-sensitive on some servers):

- **post.png** — 支柱 (scaffolding post ø48.6, MA series)
- **jack-base.png** — ジャッキベース (adjustable jack base)
- **plank.png** — 踏板 Anchi (perforated metal plank)
- **nuno.png** — 布材 / 手摺 (nuno bars / ledgers with hook ends)
- **brace-handrail.png** — ブレス・手摺 (X-brace with handrail)

The viewer will load them and apply them to the 3D components. If a file is missing, that component falls back to the standard solid material.
