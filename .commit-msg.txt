feat(bim): gap #10 follow-up - true window holes (no CSG)

Replaces the gap #5/#10 "windows-as-applique" approach with real
cut-outs in the wall geometry. Windows are now actual openings: looking
through one shows the building interior / opposite wall, not the back
of an applied glass tile. No CSG dependency added.

Approach
- Walls extrude as zero-thickness ribbons running along each polygon
  edge (instead of the closed polygon-extrusion solid that gap #5 used).
- For each polygon edge, compute window apertures along the edge in mm
  (1.8 m wide, 3.5 m spacing, only on edges ≥ 4 m, pulled 200 mm in
  from each corner).
- For each aperture, emit FOUR rectangular wall pieces around the hole:
  * Solid wall section before the aperture (full height, baseY..topY).
  * Sill below the aperture (full width, baseY..sillY).
  * Lintel above the aperture (full width, headY..topY).
  * Glass pane in the aperture itself (sillY..headY) using the existing
    blue-tinted curtain-wall material.
- Final solid wall section after the last aperture finishes the edge.
- Material set is DoubleSide so the ribbon renders correctly when
  viewed from inside, even though each quad is single-faced.

Implementation
- New extrudeWallRibbonWithWindows() and pushWallQuad() helpers in
  lib/bim/dxf-procedural-bim.ts. The old polygon-extrude path for walls
  is gone, along with the addProceduralWindows() applique helper.
- Slabs and roof still use the original extrudePolygonToMesh() solid
  block — they don't need cut-outs.
- Explicit window/door layer polylines (e.g. the DXF carries window
  rectangles) still get extruded as glass tiles via the existing path
  on top of the new ribbon walls.
- Pure unit-conversion fix in pushWallQuad: scene_m = DXF × scale ÷ 1000
  (not the inverse of dxfPerMm path).

Quality
- Frontend tsc --noEmit passes.

Honest scope:
- Walls have zero physical thickness in this model — looking edge-on
  shows a paper-thin band. For most building views (orbital, 3/4) this
  is invisible. If we ever want thick walls with mitred corners, that's
  a separate polygon-offsetting task.
- Sill/lintel meet the wall ribbon edge cleanly because everything sits
  on the same plane; there's no z-fighting.
