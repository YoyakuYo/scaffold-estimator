feat(bim): gap #10 - procedural facades and roof for DXF BIM extrusion

Builds on gap #5 to make DXF buildings actually look like buildings.
Walls, slabs, roof + procedural windows + explicit window/door openings.

Changes
- Procedural window panes (blue glass via the existing PBR material):
  * Walked edge-by-edge over every wall polygon.
  * Edges longer than 4 m get one window every 3.5 m, ~1.8 m × 1.5 m,
    sill at 0.9 m, 50 mm pane thickness oriented along the wall normal.
  * Picks up the curtain-wall blue tint from getMaterialForElement.
- Explicit opening layers ("window"/"窓"/"door"/"扉"/"opening") are now
  honoured: each closed polyline on those layers becomes a glass pane of
  its own bounding box, sitting at sill height.
- Roof: when no roof-tagged polygon exists, falls back to extruding the
  outermost slab outline as a roof — the building always has a top,
  picked up by the slate roof material.

These run entirely client-side; no new backend code, no extra deps.

Quality
- Frontend tsc --noEmit passes.

Honest scope:
- Walls don't get holes punched in them where windows go — windows sit
  on the outside face. That's the standard "extrusion + applique"
  approach used by quick-look BIM tools; it reads correctly at building
  scale but looks slightly toy-like up close. Real cut-outs would need
  CSG (three-bvh-csg or similar), which we can add later.
- Roofs are still flat; hipped/gabled inference from outline is its own
  multi-day job.
