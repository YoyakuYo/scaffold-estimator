feat(construction-plan): phase 3 structural takeoff foundation (no-AI default)

Construction Plan product gets its end-to-end takeoff foundation:
projects, drawing-set batch uploads with deterministic auto-classification,
and a per-floor x per-block manual element editor for the eight structural
categories. Gated behind @RequiresProduct('construction_plan') from Phase 2.

Backend
- Migration 136 creates construction_plan_projects, drawing_sets,
  drawing_set_files, and extracted_elements with service-role RLS.
- New backend/src/modules/structural-takeoff with:
  - element-types.ts (StructuralElementType, DrawingKind, sources).
  - drawing-classifier.ts: deterministic filename heuristics for 1F-RF/B1F/PH,
    工区, 伏図/柱リスト/梁リスト/階段詳細/EVシャフト/階高表 etc. Pure regex,
    no AI key required, returns confidence 0-1.
  - Entities for project, drawing set, drawing set file, extracted element.
  - StructuralTakeoffService: project CRUD, set lifecycle, batch file upload
    with auto-classification, manual classification override (manual source
    is sticky, never overwritten by re-runs), element upsert/delete, and a
    composite getSetReview() for the front-end one-shot fetch.
  - StructuralTakeoffController: REST surface
    GET/POST /structural-takeoff/projects, project CRUD, set CRUD,
    multi-file POST /sets/:id/files (FilesInterceptor, 30 files / 50 MB each),
    PATCH /sets/:id/files/:fileId for classification overrides, element
    upsert/delete. Records every batch upload in upload_events so the
    superadmin cockpit shows construction_plan uploads in the unified feed.

Frontend
- lib/api/structural-takeoff.ts: typed client + StructuralElementType /
  DrawingKind constants.
- /construction-plan home page: lists projects (gated, locked overlay when
  the user has not subscribed) and a create-project form with blocks/levels
  CSV input.
- /construction-plan/[projectId] page: project header with level/block
  badges + drawing-set list + new-set button.
- /construction-plan/[projectId]/sets/[setId] review page:
  - Multi-file drag-and-drop upload (PDF/image/DXF/DWG/JWW/Excel/CSV).
  - Auto-classification grid showing per-file kind/level/block + confidence;
    user can override and provenance switches to "manual".
  - Per-floor x per-block element editor for the 8 categories
    (柱 / 大梁 / 小梁 / 耐風梁 / ブレース / 階段 / エレベーター / デッキ);
    add rows from quick-add buttons; "Save all" performs a single upsert.
- ja/en/fr keys for landing, project, and review screens.

Quality

- Frontend tsc --noEmit: passes.
